# Learning Checklist

Do not move to full automation until you can explain each item.

## Jira
- [ ] I can create a project and issue.
- [ ] I understand workflow statuses and transitions.
- [ ] I can write measurable acceptance criteria.

## MCP
- [ ] I can explain host/client/server.
- [ ] I can connect Atlassian MCP.
- [ ] I can perform a read operation.
- [ ] I can perform an explicit safe write.
- [ ] I know MCP is a connector/capability layer, not the lifecycle itself.

## Agent
- [ ] I separate planning from implementation.
- [ ] I inspect `git diff` after agent changes.
- [ ] I understand why human approval remains important.

## Git/GitHub
- [ ] I use feature -> staging -> main.
- [ ] I can create and review a PR.
- [ ] I understand why the agent should not merge automatically in v1.

## CI/CD
- [ ] I can explain CI vs deployment.
- [ ] I can intentionally break a CI check and fix it.
- [ ] I can locate a Vercel staging preview.

## Completion
- [ ] I completed ADLC-3 end-to-end.
- [ ] I can draw the architecture without reading the guide.
- [ ] I can explain which steps are agentic, deterministic and human-controlled.
